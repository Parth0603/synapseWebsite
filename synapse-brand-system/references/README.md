# Global Design References
## Repository of visual standards, architectural blueprints, and corporate brand guidelines.

### What Belongs in This Folder:
1.  **Brand Assets:** Original SVG logos, vector graphics, icons, and official color swatches.
2.  **Sponsor Assets:** SVG vector logo kits from sponsors to ensure flawless glassmorphic integration.
3.  **Creative Briefs:** Documents defining high-level messaging, narrative outlines, and copy guidelines.

### Naming Conventions:
*   `logo_synapse_primary.svg`
*   `logo_synapse_monochrome.svg`
*   `partner_[company_name]_[color/mono].svg`

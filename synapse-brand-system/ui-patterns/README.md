# UI Patterns & Modular Layouts
## Reusable structural components and layouts.

### What Belongs in This Folder:
1.  **Component Design Schemes:** Specifications for custom glassmorphic cards, terminal panel structures, and interactive accordions.
2.  **Form Elements:** Unified designs for registration inputs, glowing selection cards, and form feedback loops.
3.  **UI Borders & Dividers:** Vector blueprints or CSS codes for modular, clean 1px borders, grid dividers, and retro terminal frames.

### UX Rule:
Keep components modular, reusable, and simple. Standardize on clean, consistent CSS variables to make visual adjustments across the site painless.

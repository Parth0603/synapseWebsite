# Hero Section References
## Assets, layouts, and interactive blueprints for the landing interface.

### What Belongs in This Folder:
1.  **Layout Blueprints:** Wireframes and layout explorations for the main headlines, CTAs, and dynamic widgets.
2.  **Particle & Smoke Shaders:** Custom shader files (`.frag`, `.vert`) or reference links for creating the high-performance background void animations.
3.  **Typography Mockups:** Typography experiments testing font weight combinations of Inter and Outfit inside the dark atmospheric context.

### Cinematic Goal:
The Hero section must command immediate visual authority. Keep designs here bold, spacious, and highly focused on the primary registration conversion path.

# Motion References & Animations
## Interactive behavior and animation standards.

### What Belongs in This Folder:
1.  **Interaction Captures:** Screen recordings (`.mp4`, `.webm`) of premium micro-interactions, spring mechanics, and custom easing curves in action.
2.  **Code Snippets / Codepens:** Reference links and code blocks for advanced cursor tracking and text mask animations.
3.  **UI Physics Models:** Technical documentation or video references showing the weight, speed, and dampening of UI elements during hover or scroll actions.

### Animation Guideline Reminder:
Every reference here must follow the standard cubic-bezier timing limits and hardware-accelerated transformation laws. No loose, bouncy springs or performance-heavy width animations.

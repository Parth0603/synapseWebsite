# Typography & Type Scale
## Font pairing, sizing, and contrast specifications.

### What Belongs in This Folder:
1.  **Font Files / Links:** Official Google Font links and local font configs for **Inter** (Body/Data) and **Outfit** (Headers/Titles).
2.  **CSS Variable Declarations:** Custom tailwind configurations and CSS type-scale definitions.
3.  **Contrast Guidelines:** Rules for typographic hierarchy over dark background images and glow shapes to guarantee premium accessibility (WCAG AAA standard).

### Type Hierarchy Summary:
*   **Main Headlines:** `Outfit` (bold/extra-bold), tracked closely (`letter-spacing: -0.02em`).
*   **Subheadings:** `Outfit` (semi-bold/medium), tracked wider (`letter-spacing: 0.05em`) for a technical feel.
*   **Body & Numbers:** `Inter` (regular/medium) with ample line height (`leading-relaxed`) for absolute reading comfort.

# Visual Inspirations & Mood Boards
## Atmospheric and aesthetic touchstones for SYNAPSE 1.0.

### What Belongs in This Folder:
1.  **Atmosphere References:** Screenshots of cinematic web experiences, film stills (e.g., *Stranger Things* title sequence, *Blade Runner 2049* color grading), and game interface mockups.
2.  **Aesthetic Boards:** Curated images showcasing high-contrast dark modes, smoky lighting effects, and vector blueprints.
3.  **UI Moods:** References to premium glassmorphism, glowing micro-borders, and tactile physical grids.

### Core Direction Notes:
Keep visual references heavily focused on dark, high-contrast, double-glow (purple/orange) environments. Avoid generic bright tech UI.
